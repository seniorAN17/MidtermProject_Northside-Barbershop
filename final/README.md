# Northside Barbershop (Midterm project)

Two pages: `index.html` (home) and `booking.html` (prices, form, FAQ). One stylesheet: `css/style.css`.
Open with Live Server (internet is needed for Bootstrap and Google Fonts).

## Where each topic is
- Semantic HTML: header, nav, main, section, footer on both pages
- Form: `booking.html`, BOOKING (fieldset, legend, label for/id, required, min/max, maxlength, radio group)
- Table: `booking.html`, PRICES (caption, thead, tbody, tfoot, th scope, colspan)
- Own Grid + own media queries (768px and 1024px, mobile-first): SERVICES, `.services-list`
- Own Flexbox: `.barber .card-body` and `.hours-line`
- Bootstrap grid: HERO, ABOUT, BARBERS (row-cols), BOOKING (col-lg-7 / col-lg-5)
- Hidden on phone: hours box in the hero (d-none d-md-block). Only on phone: "Call us" (d-md-none)
- Bootstrap components: navbar, cards, accordion
- Memorable: barber pole stripe (gradient), running stripe animation (@keyframes), hover on cards
